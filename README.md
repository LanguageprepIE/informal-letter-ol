# LC OL Spanish — Quick Revision Hub

Independent static website for Leaving Certificate Spanish Ordinary Level revision.

## Sections
Vocabulary, grammar, writing, five reading comprehensions, and study plan.

## Improvements in v2
- Added reading answer workspaces (saved locally in the current browser; no accounts or server storage).
- Added a working 20-minute focus / 5-minute break timer.
- Improved keyboard focus, mobile layout and reading-page stylesheet references.
- Added Reading to homepage and softened unverified claims about official SEC marking.

## Deployment
Deploy the **contents of this folder** as a static site on Netlify, with the publish directory set to the repository root (`.`). No build command is needed.

## Notes
Review all content against current SEC examination materials before classroom use. Do not rely on this site as an official marking scheme.
